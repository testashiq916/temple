# Temple ERP — Devotee Mobile App

Flutter devotee portal for the Temple ERP platform: sign in, browse and book
sevas, make donations, view donation history, and manage your profile. Talks
to the same Laravel API (`backend/laravel`) used by the web-admin console.

## Status

This directory contains the app's Dart source (`lib/`) and `pubspec.yaml`
only. The platform folders (`android/`, `ios/`, etc.) are generated by the
Flutter tooling and are intentionally not checked in — this scaffold was
authored in an environment without the Flutter SDK installed, so it has not
been built or run. Before first run, generate the platform scaffolding and
fetch packages:

```bash
flutter create --project-name temple_erp_devotee_app .
flutter pub get
```

Then run against a local backend (Android emulator maps `10.0.2.2` to the
host machine's `localhost`):

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1
```

For a physical device or iOS simulator, point `API_BASE_URL` at your
machine's LAN IP or a deployed API URL instead.

## Structure

```
lib/
├── config/api_config.dart      # API base URL (overridable via --dart-define)
├── models/models.dart          # DevoteeUser, Temple, SevaService, SevaSlot, SevaBooking, Donation
├── services/
│   ├── api_client.dart         # HTTP + Sanctum token persistence (SharedPreferences)
│   ├── auth_provider.dart      # Session state (ChangeNotifier)
│   └── temple_service.dart     # Seva/donation API calls
├── screens/
│   ├── login_screen.dart
│   ├── dashboard_screen.dart   # Bottom-nav shell: Home / Seva / Donate / Profile
│   ├── seva_booking_screen.dart
│   ├── donation_screen.dart
│   └── profile_screen.dart
└── main.dart
```
